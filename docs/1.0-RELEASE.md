# GraphSAG 1.0.0 Release Definition

GraphSAG 1.0.0 is a **security-governance kernel/reference implementation**, not a blanket certification of every deployment.

## 1.0 acceptance gates

1. Constitution and authorization invariants are executable and tested.
2. Required-provider failure is fail-closed.
3. Audit failure is fail-closed for High/Critical actions.
4. Evidence has request/generation/principal/provider/registry binding.
5. Evidence integrity can be cryptographically verified.
6. Replay and expiry controls exist.
7. Decision execution can be capability-bound.
8. Audit history can be durably chained and verified.
9. Provenance graph can reconstruct decision inputs.
10. Adaptive governance is constitution-constrained.
11. CI runs tests and compilation checks.
12. Production-specific controls remain explicitly documented as deployment responsibilities.

## 1.0 non-claims

GraphSAG 1.0.0 does not claim universal compliance, formal verification, zero vulnerabilities, or safety certification. It provides enforceable kernel invariants and integration boundaries that a deployment can harden and independently validate.
